# 旁问（/btw）

## 功能

在输入框中输入 `/btw <问题>`，仅凭当前对话已有的内容——消息、回复与工具结果——回答问题；不提交任何内容，也不新增 Session 事件。问答显示在右侧边栏的旁问标签页中——一段读取整场对话、却从不写回对话的并行聊天；它保留该会话最近的问答以便追问，并随 Host 进程结束而消失。

## 原理

- 客户端的 `btw` '/' 源接管整行 `/btw …`（单独的 `/btw` 展示空标签页）。携带附件的行会被拒绝，草稿保持不变。
- 标签页调用 `btw` Remote：`ask`（问题及附加图片）、`history`、`clear`；回答以 Markdown 渲染。
- 输入框可附加图片（会话路由须支持视觉）；装有语音能力的 bundle 时，还可把录音的问题转写进草稿。
- 宿主引擎序列化会话的模型可见历史，连同保留的问答与问题一起组帧，并在会话自身的路由（或配置的 `provider`/`model` 对）上发起一次纯文本模型调用（无工具）。

## 限制

- 回答一次性返回；没有流式输出，也没有追问轮次。
- 保留仅在内存中；Host 重启即清空。
- 尚无请求头的会话在未配置 `provider` 与 `model` 时会拒绝首条旁问。
