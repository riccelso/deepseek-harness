# @deepseek-ai/dsh-experimental-api-btw

English | [中文](README.zh.md)

## Summary

This TypertRemoteService exposes `ask`, `history`, and `clear` on the `btw` Remote namespace. Side questions never submit to the Session's own Agent and add no message or tool result to its log.

## Use this package

Load through the [btw bundle](../btw-bundle/README.md). Browser clients mount the `./remote` contribution and call `ctx.remote.btw.ask(sessionId, question, images, signal)` — `images` are canonical-base64 image attachments; a failing call surfaces as one `btw/ask-failed` RemoteError whose `details.reason` carries the engine's diagnostic.

## Understand the implementation

Each method validates cancellation, delegates to `ctx.btw` from [btw](../btw/README.md), and wraps ask failures in one stable RemoteError; history and clear are synchronous reads over the same engine.

## Further Exploration

The browser half that mounts this contribution is [client-ui-btw](../client-ui-btw/README.md).

## Dev Note

The `lib/typert.*` artifacts are generated by `scripts/generate-typert.ts`.

## Model Experience

None, as this package never enters the model context; it transports side questions to the engine.

#### KV Cache effect

None. The Remote adds no model request; the engine's one auxiliary call is documented in its own package.

## Known Limitations and Deferred Work

- Streaming answers are deferred; every ask returns one completed exchange.
